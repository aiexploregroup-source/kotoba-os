# Japanese Learning Resources — Master Research Table (2026)

**Scope:** A comprehensive curated list of the major official, free, freemium, and paid Japanese-learning resources currently available online, based on research done in November 2026. It is not literally *every* app ever published (that changes daily), but it covers the widely used, highly rated, and institution-backed resources found across current roundups and official directories.

**Prices:** Indicative only. They were checked against 2026 sources where possible and can change by country, platform, and promotion. Many “best” lists are affiliate-funded, so verify on the provider’s own site before paying.

**Legend:** Free = no payment needed for core use · Freemium = useful free tier + paid upgrades · Paid = purchase/subscription required · One-time = single payment.

## 6. Quick recommended study stacks

| Goal | Recommended stack |
|---|---|
| 100% free | NHK Easy Japanese + Tofugu hiragana guide + Tae Kim/Wasabi + Anki + Jisho + NHK Web Easy + Misa/ToKini Andy/Japanese Time on YouTube |
| Low-cost solid foundation | Renshuu or Bunpro + WaniKani + JapanesePod101 + Satori Reader free/paid + occasional italki/Preply lesson |
| JLPT N5–N1 | Bunpro + WaniKani/Anki + JLPT official samples + Nihongo no Mori + tutor mock tests |
| Speaking-first | italki or Preply (2–3×/week) + Speechling/Pimsleur + Dogen + Japanese Ammo/Miku Real Japanese |
| Reading/immersion | Satori Reader + NHK Web Easy + Jpdb + Matcha + Game Gengo/Japanese Time + native manga/anime |
